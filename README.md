# Finkeissen Research Architecture

Central entry point to the **Finkeissen Research Architecture** —  
a coherent, layered, constraint-based knowledge framework.

All repositories listed below form **one unified system** and must be interpreted together.

## Layered Architecture Overview

The system consists of clearly defined structural layers:

### Layer 0 – Epistemic Admissibility & STOP Kernel
- **research-program**  
  https://github.com/finkeissen/research-program  
  Defines admissibility rules, epistemic constraints, and STOP conditions.

### Layer 1 – Effect-Relation Grammar Kernel
- **physik-effekt**  
  https://github.com/finkeissen/physik-effekt  
  Defines foundational effect ontology and measurement grammar.

### Layer 2 – Domain Instantiation Layer
- **forschungsprogramm-medizin**  
  https://github.com/finkeissen/forschungsprogramm-medizin  
  Reference domain: medicine (uncertainty, vital stakes)

- **forschungsprogramm-recht**  
  https://github.com/finkeissen/forschungsprogramm-recht  
  Reference domain: law (coercion, contested norms)

### Layer 3 – Operational Constraint Engine
- **mms**  
  https://github.com/finkeissen/mms  
  Matrix Management System for runtime constraint enforcement.

### Layer 4 – Admissible Artifact Ledger
- **matrix**  
  https://github.com/finkeissen/matrix  
  Registry of context-bound admissible artifacts.

### Pre-Formal Archive Layer
- **legacy**  
  https://github.com/finkeissen/legacy  
  Archive of assumptions, contradictions, and boundary cases.

---

## Unified System Declaration

The repositories above form one coherent architecture defined by:

- uniform epistemic STOP conditions  
- context-bound claims only  
- effect-relation ontology (not substance ontology)  
- layered constraint propagation  
- explicit exclusion of implicit authority  

Each repository represents a structural layer of the same framework.
